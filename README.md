# Logica_de_Programacao
Nesta matéria, estudamos os fundamentos da programação utilizando a linguagem Python no Google Colab. Aprendemos conceitos como armazenamento de dados, variáveis, condicionais, estruturas de repetição, modularização, vetores e matrizes. Também desenvolvemos o pensamento computacional, aprendendo a organizar ideias e criar soluções para problemas por meio da programação.
